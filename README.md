# Сложно сосредоточиться

Адаптивный лонгрид о том, почему трудно концентрироваться и как с этим справиться. Проектная работа Яндекс Практикума.

## Что реализовано

- Вёрстка под три размера экрана из макета — 375, 768 и 1024 px — по подходу mobile first. Между ними сетка тянется без горизонтального скролла.
- Светлая и тёмная темы. По умолчанию тема берётся из настроек системы через `prefers-color-scheme`, переключатель в шапке задаёт её принудительно.
- Раскладка на CSS Grid, логические свойства, цвета и отступы в CSS-переменных.
- Состояния `:hover` и `:focus-visible` у ссылок и кнопок, ленивая загрузка изображений.

## Технологии

HTML, CSS, JavaScript

## Структура стилей

| Файл | Назначение |
| --- | --- |
| `styles/globals.css` | Сброс браузерных стилей |
| `styles/variables.css` | Переменные тёмной темы и размеров для разных экранов |
| `styles/style.css` | Основные стили и медиазапросы |
| `styles/dark.css`, `styles/light.css` | Переопределения для тем |

## Запуск

Откройте `index.html` в браузере.
